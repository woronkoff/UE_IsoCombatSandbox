# UE Isometric Combat Sandbox

A small Unreal Engine C++ learning project.

## Long-term purpose

This project trains systems that may later be useful for an original isometric online PvPvE action game.

## Current scope

This is not an MMO, not an open-world game, and not a full RPG.

The first prototype focuses only on:

- basic character control
- isometric-style camera
- mouse aiming
- health
- melee attack
- projectile skill
- cooldowns
- simple debug UI
